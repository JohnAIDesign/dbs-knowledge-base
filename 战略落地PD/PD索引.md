# PD卡片索引

> 校正版 · 2026-09-30。概念依据与实施建议分开标注；步骤、模板和海顺试点安排属于教学设计。海顺实际基线、目标、负责人和资源尚待确认。

先读D00，再按当前问题阅读D01—D12。

| ID | 卡片 | 定义摘要 |
|---|---|---|
| D00 | [[D00_战略落地总纲]] | 把战略选择、突破目标、年度进展、流程优先改善、效果指标、资源和学习评审连接成运行闭环。 |
| D01 | [[D01_战略部署定义与价值]] | 将关键战略选择转化为少数突破、资源承诺与持续学习的管理过程。价值在于集中力量、跨职能对齐和根据事实纠偏。 |
| D02 | [[D02_PD七阶段流程与时间表]] | 课件以七个阶段组织从愿景、战略到执行、回顾的年度部署过程；阶段名称是流程骨架，反馈可使前序决定被修订。 |
| D03 | [[D03_突破性目标]] | 描述跨年度需达到的重大经营结果与能力跃迁，体现战略取舍和显著差距。 |
| D04 | [[D04_年度突破目标]] | 将跨年度突破转化为本年度需要实现的可验证进展，并与年度资源安排相连。 |
| D05 | [[D05_最高层优先改善]] | 为实现年度突破而优先建立或改变的关键流程机制，包含从流程改变到经营结果的可检验贡献假设。 |
| D06 | [[D06_改善指标TTI]] | TTI表达优先改善需要达到的效果水平和期限；必须把测量定义与目标陈述一起管理。 |
| D07 | [[D07_关键资源与多功能团队]] | 为突破明确真正可投入的人力、时间、能力、资金与跨职能协作，使责任与执行条件匹配。 |
| D08 | [[D08_战略部署矩阵与层级联接]] | 用矩阵显示目标、优先改善、指标、责任和资源之间的关系，通过上下及横向协商形成可执行承诺。 |
| D09 | [[D09_冲击点与行动计划]] | 把改善落到可以实施变化、观察事实和验证效果的具体工作环节及责任动作。 |
| D10 | [[D10_月度评审与对策]] | 以同口径实际结果检验部署假设，处理偏差、资源障碍和能力缺口，并记录决定的学习机制。 |
| D11 | [[D11_年度自诊断与实施纪律]] | 回顾经营结果、能力建立、战略假设及资源配置，决定下一年度继续、调整、停止或转入常态运行。 |
| D12 | [[D12_PD与日常管理KPI的边界]] | PD聚焦关键能力与绩效突破的选择和部署；DM维持日常标准、响应异常并持续改善；KPI是衡量指标，不是DM本身。 |
