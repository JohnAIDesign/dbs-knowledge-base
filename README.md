# 海顺新材 · DBS 知识体系

以丹纳赫商业系统（DBS）为框架、面向海顺新材“从战略到落地执行”的知识图谱与落地手册。

## 入口

- 浏览器打开 [`DBS知识地图.html`](DBS知识地图.html)：体系总图、PD运行、战略落地、海顺QDC、今天做什么、模块工具、岗位学习、配套手册八个视角，可点击与全文搜索。
- Obsidian 打开本目录：五张 Canvas 总图（`01_`～`05_*.canvas`）。
- 文字入口：`00_学习入口.md` → `10_知识总索引.md`。

## 结构

| 目录/文件 | 内容 |
|---|---|
| `00_`–`15_*.md` | 体系总论、运行流程、实施节奏、指标、模拟训练、模块目录与白话词典 |
| `海顺01`–`海顺04` | 海顺落地篇：诊断与首月、岗位带教、PD术语、战略到执行总纲 |
| `F01`–`F06` | 职能落地手册：研发、供应链、销售、财务、HR、质量EHS |
| `X01`–`X03` | 机制：成熟度自评、AAR复盘、Yokoten横向复制 |
| `战略落地PD/` | 战略落地PD子图谱 D00–D12（依据 PD 课件 61 页） |

| `模板/` | 14 份可填写工作模板 |
| `图谱/` | 知识图谱数据（节点表、关系表、JSON） |

## 边界说明

- 本库为学习与试点用的**教学操作化**整理，不冒充丹纳赫内部培训或认证教材。
- 涉及海顺新材真实数据、目标、责任人与日期处，一律以【待海顺确认】占位，未填造。
- 连线/关系表达管理逻辑与来源，不自动证明统计因果。

模块工具可筛选全部工具、34张通用补充或20张海顺先学工具。工具名称的来源与通用执行建议分开标明，完整目录见 [[14_模块工具目录与来源覆盖]]，缩写解释见 [[15_术语白话与易混概念]]。
