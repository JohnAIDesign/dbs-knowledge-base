# 价值分析与价值工程

**T18 · Value Analysis / Value Engineering — VA/VE · 精益 · 书中历史工具**

## 一句话理解

保住所需功能，找到总成本更合理的实现办法。

## 定义

从产品或服务必须实现的功能出发，寻找在满足要求前提下更经济的设计与实现方式。

## 何时用

成本受设计、材料、规格和制造方法影响较大。

## 输入与动作

**需要的输入：**功能要求、成本构成、客户与质量边界、验证条件。

1. 明确必要功能。
2. 分解功能与成本。
3. 提出替代。
4. 验证性能和总成本。
5. 完成适用批准。
6. 跟踪实际效果。

## 必须产生的东西

有功能证据、成本分析及验证记录的替代方案。

## 怎样验收

必要性能满足，生命周期总成本降低；变更条件和客户要求得到落实。

## 误区与边界

只换便宜材料，不考虑可靠性、工艺能力、验证和客户使用。

## 小场景：如何落地

模拟：替代材料先证明必要性能与工艺可行，再比较材料、返工、验证及客户使用的总成本。

> 场景用于解释方法，不代表海顺实际事件或已实现效果；数值若出现均为教学模拟。


## 海顺怎样用

- 触发证据：功能要求、实际成本与替代方案。
- 责任与部署：研发、采购、质量验证功能与全成本。
- 记录入口：[[TPL01_改善项目章程]]；只使用当前问题需要的字段，避免为了填表另建项目。
- 共同验收：本轮围绕产品质量、交付期和成本控制；明确主要效果与另外两项约束。库存是支持指标。真实数据与目标待确认。

## 10分钟启动练习

挑一个高成本部件或步骤，先写功能再想替代。
