# 5S

**T11 · Sort / Set in Order / Shine / Standardize / Sustain · 共同基础 · 历史公开工具**

## 一句话理解

让必需物品、正确位置和异常状态一眼可见。

## 定义

通过整理、整顿、清扫、标准化和持续维持，使工作环境和异常更容易识别。

## 何时用

查找、错取、污染、混放或基础状态不可见。

## 输入与动作

**需要的输入：**工作需要、物品/文件使用情况和风险。

1. 区分必要与不必要。
2. 按使用和风险定位。
3. 清洁并发现异常。
4. 建立位置与状态标准。
5. 日常复查。

## 必须产生的东西

位置、数量、状态和维护责任清楚的环境。

## 怎样验收

找取时间、错取和异常发现改善，不只是检查分数高。

## 误区与边界

把5S做成大扫除；未解决混料或异常识别。

## 小场景：如何落地

模拟：把相似物料分区并标明可用、待检、隔离状态，用错取与找取时间检验，不能只看整齐。

> 场景用于解释方法，不代表海顺实际事件或已实现效果；数值若出现均为教学模拟。


## 海顺怎样用

- 触发证据：寻找、误取、污染或安全隐患事实。
- 责任与部署：岗位人员定义必要物品、位置与异常恢复。
- 记录入口：[[TPL09_标准化与移交验收]]；只使用当前问题需要的字段，避免为了填表另建项目。
- 共同验收：本轮围绕产品质量、交付期和成本控制；明确主要效果与另外两项约束。库存是支持指标。真实数据与目标待确认。

## 10分钟启动练习

选择一处工具或文件区域，测量一次查找并设计可视定位。
